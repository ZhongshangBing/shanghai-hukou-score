# 上海落户模拟打分工具

依据《2026 年非上海生源应届普通高校毕业生进沪就业申请上海市户籍办法》和评分办法制作的离线测算工具。

打开 `index.html` 即可使用，无须安装或联网。先选择最高学历，再输入学校及专业完整代码或精确名称，页面会自动匹配直接落户通道、学校分、重点专业和计算机免考分。搜索下拉框支持模糊检索，实际计分使用代码或精确匹配。

匹配直接落户通道后，成绩和奖励自动收起，无须继续凑满 72 分。研究生和本科免考专业自动计入计算机 7 分；其他情况才显示适用的证书选项。切换学历会清空旧专业，修改专业会清空原手选计算机等级，避免旧选择影响新结果。

直接落户通道的匹配无需额外勾选，最终申请仍须符合基本条件。相关要求集中在“申报前核对基本条件”中；其他单位加分、专利、创业等项目按需展开。学校类别和就读地点一般自动识别，确需修正时再打开人工核对。

2026 年标准分为 72 分。普通受理时间为 5 月 11 日至 7 月 3 日（工作日），博士可延至 12 月 31 日（工作日）。测算结果不代表官方审核结论，也不延长受理期限。

政策原文：[上海市教委沪教委学〔2026〕13号通知](https://edu.sh.gov.cn/xxgk2_zdgz_xxxsgz_01/20260506/f4df3bb5b82747b893b1eb10ca2b1f8b.html)。

## 核验说明

- 本科及研究生采用各自的专业目录；内置附录 5 全部 361 条记录。
- 学校类别、就读地点、重点区域单位和岗位认定以申报材料及主管部门确认结果为准。名单外学校须人工核对类别及实际就读地点。
- 毕业研究生自动计入计算机 7 分，本科规定免考专业按代码识别。其他计算机证书、外语课程、奖项及创业材料仍须按页面说明核验。
- 创业 5 分和创业社保例外分别确认；前者不自动放行基本资格。
- 西部计划按毕业当年评分办法核验。对年份不明、非 2026 年或其他专项项目，页面保留参考分并标注待核验，不给出最终达标结论。
- 不联网、不保存用户填报信息，不向服务器发送个人数据。

## 验证

安装 Node.js 后运行，无第三方依赖：

```sh
node --test tests/policy.test.cjs tests/form.test.cjs
```

33 组测试使用从用户提供的政策文件独立提取的附录数据，覆盖名单完整性、专业学历分层、学校双代码、直接落户、基本条件、计算机计分、奖励封顶、单位去重、创业及专项政策，以及精简表单与政策规则的映射。
